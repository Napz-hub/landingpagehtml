Praktikum Pemrograman HTML

Bahasan: HTML, PHP, dan CSS

Penyusun: Kevin Permana, S.Kom

1. Tujuan

  • Mengenal dasar pemrograman berbasis server menggunakan HTML.
  • Mengetahui struktur dan sintaks dasar HTML.
  • Mampu membuat solusi sederhana menggunakan HTML.

2. Dasar Teori

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat halaman web. Browser seperti Google Chrome atau Mozilla Firefox akan membaca dan menampilkan struktur HTML dalam bentuk visual yang mudah dipahami pengguna.

Beberapa Elemen HTML yang Umum Digunakan:

TagFungsi
<h1> – <h6>Mendefinisikan heading atau judul
<p>Membuat paragraf
<a>Menambahkan hyperlink
<img>Menampilkan gambar
<br>Menambah baris baru
<hr>Membuat garis horizontal
<b>Teks tebal
<i>Teks miring
